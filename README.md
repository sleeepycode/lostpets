# LostPets

Full-stack приложение для поиска потерянных животных
по сходству фотографий.

## Технологии

- Frontend: React, TypeScript
- Backend: Python, FastAPI
- Database: PostgreSQL, SQLAlchemy
- Version Control: Git

## Возможности

- Просмотр объявлений о животных
- Создание объявлений
- Загрузка фотографий
- Поиск похожих животных по фотографиям

## Лабораторные работы

- ЛР №1: Интерфейс приложения и каркас frontend
- ЛР №2: Backend, API и база данных
